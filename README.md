# kNN Classifier

A basic implementation of the k-Nearest Neighbors (kNN) algorithm using Python. This project explores multiple similarity metrics and evaluation methods for classification tasks.

## Features

- Supports multiple similarity/distance measures:
  - Mean Squared Error (MSE)
  - Cosine Distance
  - Structural Similarity Index Measure (SSIM)
- Evaluation metrics:
  - Confusion Matrix
  - Precision, Recall
  - Macro-averaged F1 Score
